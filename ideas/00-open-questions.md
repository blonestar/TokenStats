# TokenStats open questions

Status: Open questions and unresolved proposals

This file records decisions that could materially change product scope,
architecture, privacy, data safety, UX, support, or release behavior. It keeps
the question visible without duplicating the official documentation. A blank
decision means the current assumption is not yet accepted.
